# ItemIcon

The tile that identifies an item in the list and the detail header.

- Logins show a monogram (the first letter of the title). Other types show their type icon.
- Sizes: `sm` (24px) in menus, `md` (32px) in list rows, `lg` (56px) in the detail header.
- APM never fetches site favicons: a request to a site would reveal which accounts you have.

Props: `name`, `letter`, `icon`, `size`, `solid`.
