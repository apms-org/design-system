# Callout

A block message inside a pane: a problem to fix or a fact to know.

- `warning` for Watchtower issues on an item, `danger` for destructive consequences, `accent` for information, `success` for a completed check.
- Title states the fact; body says why it matters; `action` offers the fix.

Props: `tone`, `icon`, `title`, `children`, `action`.
