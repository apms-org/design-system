# Select

A native select, styled as an input.

- Use for 4 or more fixed options (auto-lock delay, clipboard timeout, cipher). For 2 to 3 options prefer `SegmentedControl`.
- Keeps the platform picker, so keyboard and screen reader behavior come for free.

Props: `label`, `hint`, `options` (strings or `{value, label}`), `value`, `defaultValue`, `onChange`, `size`, `icon`, `disabled`.
