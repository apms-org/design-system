# SettingRow

One setting: title, description, and its control on the right.

- Stack rows inside a `FieldGroup`; hairlines separate them.
- Controls: `Switch` for on or off, `Select` or `SegmentedControl` for choices, `Button` for actions. `danger` for destructive rows.

Props: `title`, `description`, `icon`, `children` (the control), `danger`, `htmlFor`.
