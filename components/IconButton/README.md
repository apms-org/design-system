# IconButton

A square, icon-only button for toolbars and field rows.

- Always pass `label`: it becomes the `aria-label` and the tooltip.
- `ghost` by default (28px); `xs` (24px) inside dense rows; `secondary` when it stands alone on a surface.
- `active` marks a toggled state (the star on a favorite). `tone="success"` is the copied state.

Props: `icon`, `label`, `size` (`xs`, `sm`, `md`), `variant`, `active`, `filled`, `tone`, `href`.
