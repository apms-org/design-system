# Icon

A Lucide icon by name, drawn at 16px with a 1.75 stroke in `currentColor`.

- Sizes: 14 in badges and captions, 16 by default, 20 in empty states and the lock field.
- Resting icons take `text-tertiary`; active ones `text`; status icons their status color.
- Pass `label` only when the icon carries meaning on its own; otherwise it is hidden from assistive tech.
- `APM.icons` lists every available name. Type icons: `globe`, `timer`, `key-round`, `terminal`, `cloud`, `credit-card`, `landmark`, `id-card`, `wifi`, `sticky-note`.

Props: `name`, `size`, `strokeWidth`, `filled`, `label`.
