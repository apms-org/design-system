# Input

A labelled text field.

- Always give it a `label` or a clear `placeholder`. Put helper text in `hint`; set `invalid` to turn the hint into an error.
- Focus switches the border to `accent` with a 3px halo; invalid uses `danger`.
- Sizes: `sm` (28px), `md` (32px), `lg` (40px). Add a leading `icon` and any `trailing` node.

Props: `label`, `hint`, `hintTone`, `icon`, `trailing`, `size`, `invalid`, `disabled`, plus every native input prop.
