# Mark

The APM bird, bare or on its app-icon tile.

- Use `tile` for the app icon: the lock screen (64px) and the space switcher (28px). The tile is `mark-tile` with `mark-ink` in both themes.
- Use the bare mark (inherits `currentColor`) in running text and footers.
- Never recolor the tile, rotate the bird, or place the mark on a busy image.

Props: `size` (px, default 24), `tile` (boolean), `label` (accessible name, default "APM").
