# Badge

A short status or type label, one or two words.

- `neutral` for types ("Login"), `success` for good state ("2FA on"), `warning` for attention ("Reused password"), `danger` for compromise, `accent` for information.
- Always pair status tones with an icon or a word. `outline` for tags.

Props: `tone`, `icon`, `dot`, `size` (`sm`, `md`), `outline`, `children`.
