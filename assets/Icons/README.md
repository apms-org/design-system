# Icons

Lucide icons (ISC license), the set shadcn/ui ships with. These are the SVG sources for every icon the `Icon` component can draw.

- Drawn on a 24px grid with a 2px stroke in the source; APM renders them at 16px with a 1.75 stroke through `Icon`.
- These files are stroked in `#6e6e78` so they read on both theme grounds in this gallery. In the product, always render icons through `Icon`, which uses `currentColor`.
- Adding an icon: take it from lucide-static, add it here and to the bundle's icon map.
